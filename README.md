# Digital Pooja Veppu (Cyber Sannidhanam) 🙏✨

A hilarious, culturally resonant, and mobile-optimized single-page web application celebrating the South Indian tradition of **Pooja Veppu** and **Pooja Eduppu** during Navratri/Durgashtami.

Students can digitally surrender their modern study materials (PDFs, YouTube lecture playlists, Notion notes, 50+ open Chrome tabs) at Goddess Saraswati's feet to take a 100% guilt-free holiday break until Wednesday morning!

---

## 🌟 Features

- **Sanctum Altar Dais**: Symmetrical Kerala brass lamps (Nilavilakku), interactive hanging temple bell (Ghanta), and a movable Agarbatti stick for Aarti.
- **Web Audio Synthesis**: Native browser-generated temple bell chimes, ambient drone, Shankh conch blast, and Anti-Study alarm.
- **Pushpanjali Floral Shower**: Falling jasmine & marigold petal physics and festive confetti showers.
- **Sacred Vidyarambham Rice Tray**: Interactive brass plate to trace *"ഹരി ശ്രീ ഗണപതയേ നമഃ"* or *"ॐ"* with your fingertip.
- **Pooja Eduppu Immunity Certificate**: High-resolution downloadable certificate generated dynamically on HTML5 `<canvas>`.
- **Maha Paapam Anti-Study Trap**: Humorous alarm warning anyone who tries to touch their study materials before Wednesday morning!
- **Zero-Data Collection**: 100% client-side privacy; notes remain strictly in the user's browser `localStorage`.

---

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, JavaScript (ES6+), Web Audio API, Canvas 2D
- **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
- **Icons**: Lucide Icons
- **Fonts**: Cinzel, Poppins, Noto Serif Malayalam

---

## 🚀 Running Locally

Open `index.html` directly in any web browser, or serve with Python:

```bash
python -m http.server 8080
```

Visit `http://localhost:8080` in your browser.
